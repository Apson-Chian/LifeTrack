# LifeTrack

> 一款基于 SwiftUI 的 iOS 智能生活轨迹记录应用。

LifeTrack 是一个专注于**个人轨迹记录、活动识别、地点管理与行程分析**的 iOS 应用。

它并不是一款导航软件，而是你的个人生活轨迹助手。

当你需要导航时，可以直接跳转至高德地图；LifeTrack 则负责记录你的真实行程、识别运动方式、统计停留地点，并帮助你建立属于自己的生活轨迹数据库。

---

# ✨ 项目特点

## 📍 智能轨迹记录

- 基于 Core Location 记录真实运动轨迹
- 支持后台持续记录
- 自动过滤异常定位点
- 记录完整历史路线
- 自动统计每日移动距离

---

## 🚶 智能活动识别

结合 Core Motion 自动识别当前活动：

- 🚶 步行
- 🏃 跑步
- 🚴 骑行
- 🚗 驾车
- 🧍 静止

支持用户手动切换活动类型，避免误识别。

---

## 🔋 智能省电策略

不同活动采用不同定位策略，而不是始终高频定位。

例如：

- 静止：低功耗定位
- 步行：中等频率
- 跑步：高精度、高频记录
- 骑行：中等精度，降低采样频率
- 驾车：低频记录

在保证轨迹质量的同时，尽可能降低耗电。

---

## 📌 自定义地点

除了地图已有地点外，还支持创建自己的地点。

例如：

- 宿舍
- 实验室
- 图书馆
- 常去食堂
- 跑步入口
- 公司
- 停车位

每个地点支持：

- 自定义简称
- 正式名称
- 分类
- 图标
- 备注
- 识别半径
- 收藏

系统能够自动识别：

- 到达地点
- 离开地点
- 停留时间
- 访问次数

历史时间线也会优先显示你定义的简称，而不是一长串地址。

---

## 🗺 历史轨迹

支持：

- 按日期查看轨迹
- 地图回放
- 行程时间线
- 活动分段
- 停留地点统计

例如：

```
08:15 离开宿舍

08:18 ~ 08:30
🚴 骑行 3.2 km

08:31 到达教学楼

11:50 离开教学楼

11:55 到达食堂
```

---

## 🖼 照片轨迹

支持从相册照片读取 EXIF GPS 信息，按拍摄时间排序生成独立的照片轨迹图。

- 只使用照片自带定位信息
- 自动跳过没有定位信息的照片
- 每个照片定位点直接连线
- 使用深色发光地图视觉展示

---

## 📊 每日统计

自动统计：

- 今日移动距离
- 各活动类型距离
- 活动时长
- 停留地点
- 常去地点
- 历史访问记录

后续计划加入 AI 自动生成每日出行总结。

---

## 🧭 高德导航联动

LifeTrack 不负责导航。

当用户输入目的地后，可直接跳转高德地图进行导航。

导航结束后，LifeTrack 将根据自身记录生成完整行程。

# 🎨 UI 设计参考

本项目当前界面设计与地图交互主要参考以下 Codex UI 设计 skill 的方法论：

- `product-design:image-to-code`：用于把用户提供的轨迹图视觉参考转化为可实现的 SwiftUI 地图界面。
- `apple-design`：用于约束 iOS 交互、按钮触达区域、底部弹层和地图控件的系统感。
- `emil-design-eng`：用于打磨控件层级、动效克制、视觉密度和可点击反馈。

轨迹地图视觉目标是：真实定位点为数据源，道路方向作为显示层修正，多运动类型用不同颜色表达，同时保持深色发光轨迹的识别度。
